# YouTube Ad Blocker — Domain Blocklist
# For use with Pi-hole, AdGuard Home, or /etc/hosts
# Last updated: 2026-06-11
#
# What this blocks:
#   - YouTube's Ad SDK (imasdk.googleapis.com) — prevents most pre/mid-roll ad loading
#   - Google ad serving infrastructure
#   - Ad tracking and attribution
#
# What this does NOT block:
#   - googlevideo.com (video content and some ads share this — blocking breaks playback)
#   - Regular YouTube features (search, comments, subscriptions, etc.)
#
# Format: one domain per line (Pi-hole / AdGuard Home compatible)

# ── YouTube Ad SDK ────────────────────────────────────────────────────────────
# This is the main SDK YouTube uses to load and play ads.
# Blocking it stops most pre-roll and mid-roll ads from loading.

www.imasdk.googleapis.com
